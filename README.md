### Generating website

Running the script `make_webpage.py` will generate the website with the directory `build`. This section contains a description of what is need to run that script if you wish to modify the website.

The following pages are static, and so should be directly edited
- Main landing page: `src/pages/index.html`
- Team: `src/pages/team.html`
- Simulations: `src/pages/simulations.html`

The following pages are generated by `make_webpage.py`
- Publications: you must place an ADS API token within a file called `ADS_token`
- Images gallery: all images files must be placed in `src/images`. New images and their descriptions should be added to `src/images.yml`.
