# ColibreWebsite

This repo contains the website of the COLIBRE project. It was based on the website for the FLAMINGO project, but has been significantly edited.

### Requirements
- A small number of python packages are required, which can be found in `requirements.txt`.
- `ImageMagick` and `ffmpeg` are required for image/video conversion.
- A zipped version of the required media files can be found at `/cosma8/data/dp004/dc-mcgi1/COLIBRE/website`. **If you add new image/video files to the website then make sure to update the zipped versions.**

### Generating the website
Running the script `make_webpage.py` will generate the website with the directory `build`.

The file `src/pages.yml` defines which pages will be shown on the webpage. 
It loads the pages in `src/pages`, which can be static or generated from config files.

The following are simply copied from `src/pages`, and so should be directly edited
- Main landing page: `src/pages/index.html`
- Team: `src/pages/team.html` (although the user map is generated by `make_webpage.py`)
- Simulations: `src/pages/simulations.html` (although the mass function plot is generated by `make_webpage.py`)
- Interactive maps: `src/pages/interactive.html`

The following pages are generated by `make_webpage.py`
- Publications: you must have access to the COLIBRE ADS library (owned by Joop), and place an ADS API token within a file called `ADS_token`.
- Images: all image files should be placed in `src/images`. New media and their descriptions should be added to `src/images.yml`.
- Videos: all video files should be placed in `src/videos`. New media and their descriptions should be added to `src/videos.yml`.
- Sliders: all image files must be placed in a subdirectory in `src/slider_images`. The definition of the sliders is done in `src/sliders.yml`. Refer to a section in that yaml file and its corresponding subdirectory if you want to see how to add another slider.

Missing image/video files will be flagged when running `make_webpage.py`. However, the interactive maps (see below) are not generated by this script, and so you must verify that the links to them are working.

### Hosting the website

The website is hosted at the STRW. All the files from the `build` directory should be placed in `/disks/web1/colibre`. All the webpages are static, so no backend is required.

The interactive maps consist of a large number of png files. They are stored on the STRW system at `/net/hypernova/data2`, and there are soft links in the web directory which point to this location.

The domain colibre-simulations.org was bought for 10 years in Aug 2025 (from NameCheap by Joop). Cloudflare (set up on Rob's account) is used to redirect all requests to this page to colibre.strw.leidenuniv.nl. Google analytics is used (set up on Rob's account)
