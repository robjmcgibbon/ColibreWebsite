Dark matter only simulations

For each hydrodynamic simulation, there is a corresponding DMO simulation that uses the same initial phases and the same total number of particles. To create the initial conditions for the DMO simulation, we converted the baryonic particles from the corresponding hydrodyamic run into CDM particles.
